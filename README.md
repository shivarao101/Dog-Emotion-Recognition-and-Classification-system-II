# Dog-Emotion-Recognition-and-Classification-system II
## A Hybrid CNN–BiLSTM–Attention Model for Noise-Resilient Dog Emotion Recognition Using Augmented Mel-Spectrogram Data
The model introduces a hybrid Deep Learning based classifier designed to efficiently identify and categorize different emotional states in dogs. The hybrid classifier is built by sequentially combining three well-known Deep Learning architectures: CNN, Bi-LSTM, and Self-Attention modules.
